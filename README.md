# [OMW] Blahaj Plush

Plush, furniture and statute of the Ikea Blahaj shark. XML only.

![Splash](https://raw.githubusercontent.com/oldmanwhistler/OMWBlahajPlush/refs/heads/main/Docs/Images/blahaj_plush_splash.png)

I had a texture for an Ikea Blahaj for another mod I was working on and someone on discord mentioned they'd love a plush.

## Mod Contents

- Utility slot plush that gives +0.05 comfort and +10% learning created at tailoring bench. Needs Complex Clothing research.
- 1x1 buildable furniture decoration.
- 1x3 buildable furniture decoration.
- 1x1 statue at art bench.
- Plush and buildings will be tinted based on the material used so use white material to match the Ikea colours.
